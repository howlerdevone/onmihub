# Installation

## Stable release

To install omnihub, run this command in your terminal:

```sh
uv add omnihub
```

Or if you prefer to use `pip`:

```sh
pip install omnihub
```

## From source

The source files for omnihub can be downloaded from the [Github repo](https://github.com/nanishb/omnihub).

You can either clone the public repository:

```sh
git clone https://github.com/nanishb/omnihub
```

Or download the [tarball](https://github.com/nanishb/omnihub/tarball/main):

```sh
curl -OJL https://github.com/nanishb/omnihub/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd omnihub
uv sync
```
