2. La tabla auth.api_keys (Otros entran a tu app)Esta tabla sirve para el camino inverso. Imagina que un usuario avanzado de Omnihub o una empresa te dice: "Oye, me encanta tu robot, pero no quiero chatear por WhatsApp. Creé un script en Python en mi empresa y quiero enviarte 500 PDFs de forma automática a Omnihub todas las noches".Para que esa empresa pueda conectarse a tu API sin usar usuario y contraseña, tú les generas un token secreto (ej: omni_live_abc123...).Dónde se guarda: En auth.api_keys guardas el hash de ese token (por seguridad, nunca guardas el token en texto plano, igual que las contraseñas).Dirección: Un script externo usa esa llave para entrar de forma programática a tu API de FastAPI.
