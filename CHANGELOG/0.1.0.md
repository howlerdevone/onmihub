## omnihub 0.1.0

Initial release of the Omnihub platform foundation: a FastAPI-based backend with modular architecture for authentication, identity, organizations, and database integration.

This release establishes the core application skeleton and developer workflow for building and running the service locally.

### Highlights

- FastAPI application entrypoint with ASGI-compatible `application` export
- Modular package structure for auth, identity, organizations, and gateway layers
- PostgreSQL + asyncpg integration with shared DB client lifecycle
- Supabase-backed authentication integration and bearer-token guard flow
- CLI entrypoint via `python -m omnihub`
- Project docs, environment template, and local development support

### Notes

The project is now moving beyond the original boilerplate scaffold and into a working multi-module backend foundation.
